Veri Silme

Son güncelleme: 2026-11-03

Tüm Verileri Sil

  • Ayarlar → Tüm Verileri Sil

Tüm hesaplar, kayıtlar, fotoğraflar ve ayarlar kalıcı olarak silinir. Bu işlem geri alınamaz. Önce yedek almanı öneririz.

Uygulamada nereden?

  • Silinmiş Kayıtlar

Kullanıcı Hakları

Uygulama içindeki tüm verilerinizi doğrudan görüntüleme, düzenleme, dışa aktarma veya kalıcı olarak silme hakkına sahipsiniz. "Silinmiş Hesaplar" ekranından geri yükleme yapabilir, kalıcı silme işlemiyle verileri tamamen kaldırabilirsiniz. Ayarlar → Yedekleme içindeki "Tüm Verileri Sil" seçeneğiyle hesaplar, kayıtlar, fotoğraflar ve ayarlar dahil tüm verilerinizi kalıcı olarak silebilirsiniz. Uygulamayı silmek, tüm yerel verileri de kaldırır.

Verilerin Saklanma Şekli

Girdiğiniz veriler öncelikli olarak cihazınızda (yerel depolama) tutulur. Giriş kodu (PIN) etkinleştirdiyseniz, uygulama içeriğine sadece bu kodu bilen kişiler erişebilir. Uygulamayı cihazınızdan kaldırmanız durumunda, yedek almadığınız sürece bu veriler de silinir.

Data Deletion

Last updated: 2026-11-03

Delete All Data

  • More → Delete All Data

All accounts, entries, photos and settings will be permanently deleted. This cannot be undone. We recommend making a backup first.

Where in the app?

  • Deleted Records

User Rights

You have the right to view, edit, export or permanently delete all of your data inside the App. You can restore items from the "Deleted Records" screen, or remove data completely with permanent deletion. With "Delete All Data" under Settings → Backup you can permanently delete all of your data, including accounts, entries, photos and settings. Deleting the App also removes all local data.

How Data Is Stored

The data you enter is kept primarily on your device (local storage). If you have enabled a passcode (PIN), only people who know that code can reach the contents of the App. If you remove the App from your device, this data is deleted along with it unless you have taken a backup.

Datenlöschung

Zuletzt aktualisiert: 2026-11-03

Alle Daten löschen

  • Mehr → Alle Daten löschen

Alle Konten, Einträge, Fotos und Einstellungen werden dauerhaft gelöscht. Dies kann nicht rückgängig gemacht werden. Wir empfehlen zuvor eine Sicherung.

Wo in der App?

  • Gelöschte Einträge

Rechte der Nutzer

Sie haben das Recht, alle Ihre Daten in der App einzusehen, zu bearbeiten, zu exportieren oder dauerhaft zu löschen. Über „Gelöschte Konten“ können Sie Einträge wiederherstellen oder durch endgültiges Löschen vollständig entfernen. Mit „Alle Daten löschen“ unter Einstellungen → Sicherung löschen Sie alle Daten dauerhaft, einschließlich Konten, Einträgen, Fotos und Einstellungen. Das Löschen der App entfernt auch alle lokalen Daten.

Speicherung der Daten

Die eingegebenen Daten werden vorrangig auf Ihrem Gerät (lokaler Speicher) abgelegt. Wenn Sie einen Zugangscode (PIN) aktiviert haben, können nur Personen mit diesem Code auf die Inhalte zugreifen. Wenn Sie die App von Ihrem Gerät entfernen, werden diese Daten ohne vorherige Sicherung ebenfalls gelöscht.

Exclusão de dados

  • Mais → Excluir todos os dados

Onde na app?

  • Registros Excluídos

Direitos do Usuário

Você tem o direito de visualizar, editar, exportar ou excluir permanentemente todos os seus dados no aplicativo. Os dados que você insere são mantidos principalmente no seu dispositivo (armazenamento local). Se você ativou uma senha (PIN), somente quem conhece esse código pode acessar o conteúdo do App. Se você remover o App do seu dispositivo, esses dados são excluídos junto com ele, a menos que você tenha feito um backup.
